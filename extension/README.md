# ScalePad Migration Utility: extension folder

This is the folder you load into Chrome.

1. Go to `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this `extension` folder.
3. Pin **ScalePad Migration Utility** and click its icon to open the side panel.

See the main [README](../README.md) for setup, how-to guides for every source and utility, and troubleshooting.
